# 🌱 Agent 成长

AI 管家的自主成长系统。通过分析用户对话和工具使用数据，自动优化服务质量。

## 三个成长维度

| 维度 | 做什么 | 怎么做 |
|------|--------|--------|
| 理解用户 | 发现用户高频需求和使用模式 | 分析对话类型分布 + 时间分布 + 重复模式 |
| 优化自己 | 从错误和撤回中学习 | 统计失败率 + 分析错误原因 + 记录教训 |
| 主动服务 | 自动丰富画像、清理过期数据 | 合并重复画像 + 补充用户偏好 + 清理旧知识 |

## 使用方式

- **自动运行**：平台启动时如果距上次成长 > 24 小时，自动执行
- **手动触发**：打开本工作区，点击"立即成长"
- **定时任务**：可在定时任务工作区中配置每日自动成长

## 成长动作分级

| 级别 | 含义 | 执行方式 |
|------|------|---------|
| 🟢 | 安全动作 | 自动执行（合并画像、清理过期数据） |
| 🟡 | 需确认 | 显示按钮，用户点击后执行 |
| 🔴 | 仅参考 | 只显示建议，不提供执行操作 |

## 数据来源

- `chat.db` — 对话历史（消息模式、撤回记录）
- `chat.db/tool_logs` — 工具调用统计（成功率、错误类型）
- `memory.db` — 用户画像 + 知识库

## 核心逻辑

逻辑位于 `daozhu/growth.py`（平台核心模块），本工作区只做展示。
