# 🌱 Agent 成长（agent-review）

> 定位：073 "AI 自主生活" 的后台引擎调试面板
> 状态：基础功能完成（069 AC1-7），后续被 073 管家主循环取代展示层

---

## 这个工作区是什么

这是 AI 自主分析能力的**调试/开发面板**，不是面向用户的主入口。

核心逻辑在 `daozhu/growth.py`（不在本工作区），本工作区只是一个薄展示层。

## 当前能力（069 AC1-7 已完成）

| 能力 | 说明 |
|------|------|
| 对话模式分析 | 统计用户高频请求类型（关键词匹配） |
| 工具健康分析 | 7 天内工具失败率、错误归类 |
| 自动画像丰富 | 从对话模式推断"主要用途"和"活跃时段" |
| 过期知识清理 | 自动删除 60 天前的 tool_failure 知识 |
| 建议机制 | 🟢自动执行 / 🟡需确认 / 🔴仅展示 |

## 与 073 的关系

073（AI 自主生活）的核心循环是：**感知 → 学习 → 决策 → 行动 → 汇报**

本工作区只覆盖了"感知 + 学习"的基础部分。073 完成后：
- `daozhu/growth.py` 的分析能力会被 073 的管家主循环调用
- 分析结果不再需要用户"打开工作区页面查看"，而是由管家在主聊天中主动汇报
- 本工作区降级为**开发调试用**（查看原始分析数据、手动触发测试）

## API

| 端点 | 说明 |
|------|------|
| `GET /api/reports` | 获取成长报告列表 |
| `GET /api/stats` | 获取工具健康数据 |
| `POST /api/run` | 手动触发一次成长分析 |
| `POST /api/suggestions/{id}/confirm` | 确认执行🟡级建议 |
