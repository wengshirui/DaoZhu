# ⏰ 定时任务

管理自动化定时任务 — 让 AI 管家定时帮你做事。

## 功能

- 创建定时任务（AI 指令、脚本、API 调用）
- 灵活调度（每 30 分钟 / 每 6 小时 / 每天 / 自定义间隔）
- 执行历史记录（时间、结果、耗时）
- 暂停 / 恢复单个任务
- 补办检测（平台重启后检测错过的任务）

## 使用示例

| 任务名称 | 指令 | 间隔 |
|---------|------|------|
| 每日天气 | 帮我查一下南京今天天气 | 24h |
| 周五周报 | 总结本周完成的工作 | 每周五 |
| Agent 成长 | 执行一次 Agent 成长分析 | 24h |
| 数据备份 | 检查工作区数据是否需要备份 | 12h |

## 调度格式

| 格式 | 示例 | 含义 |
|------|------|------|
| `Nm` | `30m` | 每 30 分钟 |
| `Nh` | `6h` | 每 6 小时 |
| `Nd` | `1d` | 每天 |
| `every Nh` | `every 2h` | 每 2 小时 |
| `daily HH:MM` | `daily 09:00` | 每天 9 点 |

## 数据存储

任务数据存在 `scheduler.db`（平台根目录），包含：
- `scheduled_tasks` — 任务定义
- `task_runs` — 执行记录

## 核心逻辑

逻辑位于 `daozhu/scheduler.py`（平台核心模块），本工作区提供管理界面。
调度器嵌入主进程 asyncio 循环，每 60 秒检查到期任务。
