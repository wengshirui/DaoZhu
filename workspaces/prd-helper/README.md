# 📄 PRD 编写助手

产品需求文档(PRD)编写助手，由 AI 助力快速生成专业文档。

## 📋 功能特性

### 1. AI 生成 PRD
- 输入产品名称即可生成完整的 PRD 文档
- 支持添加产品描述以获得更精准的生成结果
- AI 自动生成产品描述功能

### 2. PRD 文档管理
- 查看已生成的 PRD 文档列表
- 点击查看详细内容
- 支持删除不需要的文档

### 3. 文档导出
- 将 PRD 文档导出为 `.docx` 格式
- 保持文档格式和结构完整

## 🚀 使用方法

### 生成 PRD
1. 点击「🤖 AI 生成 PRD」按钮
2. 输入产品名称（必填）
3. 可选：输入产品描述，或点击「🤖 自动生成产品描述」
4. 点击「🚀 开始生成」
5. 等待 AI 生成完成，自动打开文档预览

### 查看文档
1. 在侧边栏选择要查看的 PRD 文档
2. 在弹窗中查看完整内容
3. 可选择导出为 Word 文档

### 删除文档
1. 在侧边栏或文档预览中点击删除按钮
2. 确认删除操作

## 📄 PRD 文档结构

生成的 PRD 文档包含以下章节：

1. **文档信息**：版本号、修订日期、作者、修订记录
2. **背景概述**：业务背景、解决的问题
3. **产品目标**：商业目标和用户目标（SMART原则）
4. **用户研究**：目标用户群体、用户痛点、使用场景
5. **功能范围**：包含/不包含的功能清单
6. **功能详情**：用户故事、交互流程、业务规则
7. **交互说明**：页面跳转、状态变化、异常处理
8. **非功能需求**：性能、兼容性、安全性要求
9. **埋点需求**：埋点目的、事件埋点、页面埋点、用户属性、埋点规范
10. **验收标准**：可测试的验收条件
11. **项目计划**：依赖关系、时间节点、风险评估
