# 岛主 DaoZhu 🏝️

**[English](./README_en.md)** | 中文

> 你的 AI 数字小岛 — 真正属于你的个人数字主权平台。

---

## 🔑 为什么选择岛主？

| 别人的产品 | 岛主 |
|-----------|------|
| 要注册、要登录 | **不用登录** — 双击 exe 直接用 |
| 数据存在别人服务器 | **数据是你的** — SQLite 本地存储，零云端 |
| 客户端随时可能下架 | **客户端是你的** — 开源代码，打包成 exe |
| AI 对话经过第三方 | **模型也可以是你的** — 接 Ollama 本地推理 |

**一句话：你的机器就是你的服务器，你的数据永远在你手里。**

## ✨ 能做什么

- 🤖 **AI 管家** — 用自然语言管理一切，支持 DeepSeek / Ollama / 智谱 / OpenAI
- 🏗️ **一句话建造** — "帮我建个读书笔记工作区"，AI 从零生成完整应用
- 📋 **工作区** — 待办、记账、论坛、桌面宠物…… 每个独立运行，互不干扰
- 🐾 **桌面宠物** — 从 Petdex 社区领养像素宠物，拖拽弹跳，桌面陪伴
- 🎬 **火柴人剧场** — 一句话生成动画短片，AI 写剧本火柴人演
- 🧠 **越用越懂你** — 三层记忆系统，AI 记住你的偏好和习惯
- 🌐 **联网能力** — 问天气、查新闻、搜技术问题，AI 帮你搜
- 📁 **绑定文件夹** — 把任何本地文件夹变成工作区入口
- 💰 **省钱** — DeepSeek 前缀缓存（省 90% 输入费）+ 长对话自动压缩
- 🔒 **安全** — 危险操作自动拦截，权限规则可配置

## 🚀 快速开始

### 方式一：下载即用（推荐）

1. 从 [Releases](https://gitee.com/yumen2278/DaoZhu/releases) 下载最新版 zip
2. 解压到任意目录
3. 双击 `岛主DaoZhu.exe`
4. 首次运行自动安装环境，浏览器打开后按引导配置
5. 后续每次启动自动更新到最新版

> 自带 Git + uv，无需安装任何东西。

### 方式二：开发者运行

```bash
git clone https://gitee.com/yumen2278/DaoZhu.git
cd DaoZhu
uv venv .venv --python 3.11
.venv\Scripts\activate
uv pip install -e .
python daozhu_main.py
```

浏览器自动打开 `http://localhost:7788`。
