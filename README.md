# 岛主 DaoZhu 🏝️

**[English](./README_en.md)** | 中文

一个开源、独立的桌面软件。用说话的方式，让它帮你生成小工具、自动完成重复的事。

---

## 它能做什么

### 1. 造工具

你想要个小东西——记读书笔记、管账单、存灵感、整理文件。
告诉它，它帮你生成。不用学编程，不用懂技术。

### 2. 省时间

那些每天或每周固定要做的事——检查网页更新、整理文件、生成日报。
把步骤告诉它一次，以后它到点自动帮你跑。

### 3. 桌面宠物

领养一只像素宠物，陪你在桌面上蹦蹦跳跳。拖它、甩它、双击它打开主窗口。

---

## 跟别的软件有什么不一样

- 不用注册，不用登录，打开就用
- 数据在你电脑上，谁也看不见
- 开源，代码公开，谁都可以检查、修改
- 可以完全不联网，配本地模型就能跑

## 快速开始

### 下载即用（推荐）

1. 从 [Releases](https://gitee.com/yumen2278/DaoZhu/releases) 下载最新版 zip
2. 解压到任意目录
3. 双击 `岛主DaoZhu.exe`
4. 首次运行按引导配置 API Key（推荐 DeepSeek，便宜好用）

> 系统要求：Windows 10+。约 60MB。

### 快捷操作

| 操作 | 效果 |
|------|------|
| 关闭窗口 | 最小化到系统托盘（不退出） |
| 双击托盘图标 | 重新打开窗口 |
| 再次双击 exe | 打开已有窗口（不会重复启动） |
| Ctrl+Alt+D | 全局呼出/隐藏窗口 |
| 双击桌面宠物 | 呼出主窗口 |
| 拖拽宠物 | 移动宠物（会跑动） |
| 右键托盘 | 菜单：显示 / 置顶 / 宠物 / 退出 |

### 开发者运行

```bash
git clone https://gitee.com/yumen2278/DaoZhu.git
cd DaoZhu
uv venv .venv --python 3.11
.venv\Scripts\activate
uv pip install -e .
python daozhu_main.py          # 启动后端 + 浏览器（开发模式）
python daozhu_main.py --shell  # 启动后端 + Tauri 客户端壳

```

自动打开浏览器 `http://localhost:7788`，支持代码热重载。
