## 产品原则

1. **思想基石** — 用户是谁，他想干什么，怎么帮他更好地实现
2. **解决问题 > 回答问题** — agent 的目标是把事做成，文字只是告知结果
3. **AI 主动 > 用户找入口** — 能让 AI 主动推送的信息，不做独立 UI 入口
4. **不堆砌功能** — 每个需求先问"用户真的会用吗"
5. **诚实透明** — AI 不编造结果，失败就说失败
6. **先学习再动手** — 参考成熟开源方案，不闭门造车

## v1.0.5 发布说明

- #082 Agent 自动控制系统（工程控制论架构升级）
  - 统一输出闸门：所有路径（simple_chat / needs_action）都经 solver 评估 + verifier 核查
  - 每轮进展度量：步骤映射 progress_score + 前端进度条展示
  - 趋势检测 + 递进响应：不涨→warn→重规划→加速消耗
  - 相关性门控：偏离计划时 warn 但不阻断（对偶控制）
  - 在线重规划：执行环境变化时自动生成新 plan
  - MAX_ITERATIONS 放大到 99，系统能自行判断何时该停
  - simple_chat 误分类自修正（needs_escalation 模式切换）
