## 产品定位

> 岛主 = 一个本地运行的、有自主意识的 AI 伙伴。
> 它用自己的智力为用户服务，不等指令，主动思考和行动。
> 用得越久越懂你，永远不会被删除或重置。

**与其他 AI 产品的根本区别：**
- ChatGPT / Cursor / 飞书 AI：用户不来，AI 就是死的
- 岛主：用户不在的时候，AI 也在为你思考和工作

---

## 核心循环：感知 → 学习 → 决策 → 行动 → 汇报

```
┌─────────────────────────────────────────┐
│            AI 自主生活循环               │
│                                         │
│  感知 ──→ 学习 ──→ 决策 ──→ 行动 ──→ 汇报
│   ↑                                  │  │
│   └──────────────────────────────────┘  │
│         （用户回来 → 展示成果）          │
└─────────────────────────────────────────┘
```

| 阶段 | 职责 | 数据源 |
|------|------|--------|
| **感知** | 理解用户行为模式、偏好、关注点 | 对话历史、profile、工具日志 |
| **学习** | 从错误/撤回中优化、从对话中积累知识 | chat_db、撤回记录、knowledge |
| **决策** | 自主判断"现在该为用户做什么" | 感知结果 + 时间 + 上下文 |
| **行动** | 执行自己决定的任务 | 工具调用（搜索/整理/分析） |
| **汇报** | 用户回来时呈现成果和发现 | 生成问候 + 工作记录卡片 |

**As a** 岛主用户
**I want** 我的 AI 管家在我不在时也在为我工作和思考
**So that** 我每次回来都能收到有价值的信息，感觉到它越来越懂我

## 范围

### In Scope

**感知能力（原 069 维度 1）：**
- 分析近 N 天对话，提炼用户高频需求模式
- 发现用户偏好和习惯（活跃时段、常用功能、语言风格）
- 定时批量丰富 user_profile（不依赖每轮对话实时提取）

**学习能力（原 069 维度 2）：**
- 用户撤回 → 分析"什么情况下回答不好"，优化服务方式
- 工具调用低效 → 记录高效路径
- 重复被问同样的问题 → 自动创建知识条目

**决策能力（新增核心）：**
- AI 自主判断该做什么（不是固定 cron，而是有判断力的决策）
- 考虑因素：用户关注点 + 时间规律 + 待办到期 + 知识空白
- 有冷却机制：不会频繁打扰，做过的事不重复做

**行动能力（新增核心）：**
- 搜索用户关注领域的最新信息
- 整理/总结对话中的知识和经验
- 检查待办到期并准备提醒
- 检查工作区状态变化
- 用户可配置"AI 空闲时可做的任务类型"

**汇报能力（原 073 展示）：**
- 用户打开应用时（窗口 focus），AI 主动展示工作成果
- 展示为聊天中的"管家汇报卡片"（可展开/折叠）
- 工作记录持久化，可回溯查看 AI 做了什么

### Out of Scope

- AI 自动修改源码
- 跨用户学习
- 推送到手机（无移动端）
- 预测用户何时回来

## 验收标准

| # | AC |
|---|-----|
| 1 | 系统记录用户最后交互时间（发消息、打开工作区、点击操作） |
| 2 | 用户空闲超过可配置阈值后，AI 自主决策并执行至少一项后台任务 |
| 3 | AI 自主任务包含：对话复盘/总结、待办到期检查、关注领域搜索（可配置开关） |
| 4 | 用户打开应用（窗口 focus）时，AI 主动展示"管家汇报"（不依赖用户发消息） |
| 5 | 汇报内容基于真实数据（最近对话 + profile + 待办 + 搜索结果），不是空洞模板 |
| 6 | AI 从用户撤回中学习，记录"什么情况下回答不好" |
| 7 | AI 定时批量分析对话 → 自动丰富 user_profile |
| 8 | 用户可配置：空闲阈值、AI 可执行的任务类型、开关总控 |
| 9 | AI 工作记录持久化存储，用户可查看"AI 做了什么" |
| 10 | 冷却机制：连续多段空闲不重复触发（至少间隔 4h） |
| 11 | 关闭后不触发任何后台任务 |

## 安全原则

```
AI 自主行动可以做的：
✅ 读取对话历史和日志（只读）
✅ 更新 user_profile（丰富画像）
✅ 添加 knowledge 条目（积累经验）
✅ 清理过期/错误的知识
✅ 使用工具搜索信息
✅ 生成总结和建议
✅ 创建草稿（用户确认后生效）

AI 自主行动不能做的：
❌ 修改源码
❌ 删除用户数据
❌ 修改密钥配置
❌ 代替用户做决定（只建议，不执行高风险操作）
❌ 无限制消耗 API token（每轮有预算上限）
```
