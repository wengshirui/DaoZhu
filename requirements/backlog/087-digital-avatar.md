## 原始需求

> 提供数字人可以跟儿童对话沟通，包括儿童可以定义其形象、风格、背景等

---

## 提取意图

为 agent 增加一个**可视化的数字人形象** — 儿童与 agent 对话时，屏幕上有一个会动的虚拟人物陪伴。儿童可以自定义这个数字人的外观（长什么样、穿什么、在什么场景里）。

本质：从"语音+文字"交互升级为"面对面"交互感，增强儿童的沉浸感和亲近感。

| # | 模块 | 问题 | AI 猜测 | 答案 |
|---|------|------|---------|------|

## 备注

技术参考：
- **Live2D** — 2D 卡通角色驱动（嘴型/表情/动作），适合本地渲染
- **Spine** — 2D 骨骼动画（游戏级质量）
- **HeyGen / D-ID** — 云端数字人视频流（写实但需联网+收费）
- **VRM / Ready Player Me** — 3D 虚拟形象标准
- **Web Speech + CSS 动画** — 最轻量方案（纯前端）

与现有系统的关系：
- **#085 语音交互** — 数字人的嘴型需要和语音同步
- **#086 儿童工作区** — 数字人是儿童模式的视觉载体
- **#083 Edge-TTS** — 数字人说话的语音源
- **桌面宠物** — 共存关系，不替代

开发建议：
- 可以先用最轻量的 CSS/SVG 动画做 MVP（嘴型同步+简单表情）
- 后续再升级到 Live2D 或 3D（质量飞跃但开发量大）
