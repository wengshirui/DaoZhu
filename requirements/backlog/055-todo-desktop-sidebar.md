## 技术方案（Tauri）

### 架构

```
Tauri 壳 (Rust)
├── main 窗口 → http://localhost:7788 (主界面)
├── pet 窗口  → http://localhost:7788/pet.html (桌面宠物)
└── sidebar 窗口 → http://localhost:7788/sidebar.html (侧边栏) ← 新增
                        ↓ JS fetch
              http://localhost:7801/api/?today=true (待办工作区 API)
```

### Tauri 侧边栏窗口配置

```rust
WebviewWindowBuilder::new(&app, "sidebar", ...)
    .title("今日聚焦")
    .inner_size(320.0, 600.0)      // 窄条，高自适应
    .resizable(false)
    .decorations(false)            // 无边框
    .always_on_top(true)
    .skip_taskbar(true)
    .shadow(false)
    .visible(false)                // 初始隐藏，用户手动开启
```

### 自动隐藏机制

- 前端 CSS `transform: translateX()` 实现滑入/滑出
- 监听 `mouseenter`/`mouseleave` 在窗口边缘
- 收起后只露出 4px 边缘触发条

### 显示模式切换

- 配置存储在 `config.db`：`sidebar.mode` = `"tauri"` | `"browser"` | `"off"`
- /sidebar.html 页面同时支持 Tauri 窗口和独立浏览器打开
- 托盘菜单提供"今日聚焦侧边栏"开关
