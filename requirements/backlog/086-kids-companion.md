## 原始需求

> 面向儿童，完成给小孩播放故事、播放动画片、回答百科问题等

---

## 提取意图

将岛主 agent 变成一个**儿童陪伴助手** — 小孩通过语音唤醒后，可以：
1. "给我讲个故事" → AI 生成或播放故事（语音播放）
2. "我想看动画片" → 播放动画内容（火柴人剧场 / 视频）
3. "为什么天是蓝的" → 用儿童能理解的语言回答百科问题

本质：agent 的"儿童人格"+ 内容分发能力。

## 开放问题

| # | 模块 | 问题 | AI 猜测 | 答案 |
|---|------|------|---------|------|
| 1 | 用户与现状 | 目标儿童的年龄段是多少？3-6 岁（学龄前）和 6-12 岁（小学生）的需求差异很大 | 3-8 岁为主（学龄前+低年级） | |
| 2 | 用户与现状 | 家长在这个过程中的角色是什么？是完全放手让孩子自己用，还是需要家长设置/监控？ | 家长设置后孩子自己用，家长可看使用报告 | |
| 3 | 范围与影响 | 故事内容来源是什么？AI 实时生成、预置故事库、还是从网上搜索播放？ | 混合：预置经典故事 + AI 按主题生成新故事 | |
| 4 | 范围与影响 | "播放动画片"是播放在线视频（YouTube/B站），还是用火柴人剧场生成？还是本地视频文件？ | 火柴人剧场生成短动画 + 本地预置动画 | |
| 5 | 业务规则 | 儿童模式需要哪些安全限制？内容过滤、使用时长限制、禁止某些话题？ | 全部需要：内容安全过滤 + 每次使用时长上限 + 禁暴力/恐怖 | |
| 6 | 业务规则 | 回答百科问题时，回复的语言风格如何？是"幼儿园老师"风格，还是"百科全书简化版"？ | 幼儿园老师风格 — 比喻多、语气温柔、句子短、会反问互动 | |
| 7 | 业务规则 | 儿童模式和正常模式如何切换？是独立入口（"儿童模式"开关），还是 agent 自动识别是小孩在说话？ | 独立入口 — 家长手动开启"儿童模式"，切换 prompt 和内容策略 | |

## 核心场景

### 场景 1：讲故事
```
小孩："岛主，给我讲个恐龙的故事"
Agent：（切换到温柔语气）"好呀～从前有一只小恐龙叫多多..."
      （Edge-TTS 播放 3-5 分钟的故事音频）
```

### 场景 2：看动画
```
小孩："我想看动画片"
Agent："你想看什么样的？有小动物的、有太空的、还有公主的～"
小孩："太空的！"
Agent：（调用火柴人剧场生成太空主题短动画 → 播放）
```

### 场景 3：百科问答
```
小孩："为什么月亮会变形状？"
Agent："因为月亮自己不会发光哦～它就像一个球，太阳照到哪里哪里就亮..."
      （简短 + 比喻 + 反问互动）
```

## 备注

与现有系统的关系：
- **#085 语音交互**（前置依赖）— 儿童不会打字，必须语音
- **#083 火柴人剧场** — "看动画"可复用火柴人视频生成能力
- **#084 生命周期** — 儿童模式使用时间计入 agent 存活统计
- **SYSTEM_PROMPT** — 儿童模式需要切换到不同的 prompt（温柔/安全/互动）
- **Edge-TTS** — 故事朗读用温柔女声（XiaoxiaoNeural）
