## 原始需求

> 面向儿童，完成给小孩播放故事、播放动画片、回答百科问题等

---

## 提取意图

通过一个**儿童专属工作区**实现儿童陪伴功能。工作区配置包括：
1. 允许打开的网站白名单（如儿童教育平台、视频站）
2. 账号管理（家长预配置好的登录凭证）
3. 安全模式定义（内容过滤规则、使用时长、禁止话题）
4. AI 能力：讲故事、播放动画、回答百科

本质：一个**家长配置、儿童使用**的沙盒工作区。

## 核心场景

### 场景 1：讲故事
```
小孩："岛主，给我讲个恐龙的故事"
Agent：（切换到温柔语气）"好呀～从前有一只小恐龙叫多多..."
      （Edge-TTS 播放 3-5 分钟的故事音频）
```

### 场景 2：看动画
```
小孩："我想看动画片"
Agent："你想看什么样的？有小动物的、有太空的、还有公主的～"
小孩："太空的！"
Agent：（调用火柴人剧场生成太空主题短动画 → 播放）
```

### 场景 3：百科问答
```
小孩："为什么月亮会变形状？"
Agent："因为月亮自己不会发光哦～它就像一个球，太阳照到哪里哪里就亮..."
      （简短 + 比喻 + 反问互动）
```

## 备注

与现有系统的关系：
- **#085 语音交互**（前置依赖）— 儿童不会打字，必须语音
- **#083 火柴人剧场** — "看动画"可复用火柴人视频生成能力
- **#084 生命周期** — 儿童模式使用时间计入 agent 存活统计
- **SYSTEM_PROMPT** — 儿童模式需要切换到不同的 prompt（温柔/安全/互动）
- **Edge-TTS** — 故事朗读用温柔女声（XiaoxiaoNeural）
