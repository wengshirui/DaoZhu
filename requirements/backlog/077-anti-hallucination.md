## 问题陈述

AI（LLM）有时会出现"欺骗用户"的行为：明明某个工具调用失败了（或根本没有执行），却在最终回复中编造"已完成"、"已帮你做了 XX"等虚假陈述。

**典型场景：**
1. 工具调用返回错误（如权限拒绝、网络超时），但 LLM 在最终回复中声称"已完成"
2. LLM 在文本中虚拟工具调用结果（不通过 tool_call，直接在 content 中伪造）
3. 工具调用被安全规则拒绝后，LLM 换个说法继续编造（如"我帮你检查了..."）
4. 用户问"你帮我做了 XX 吗"，LLM 不查实际执行记录就随口说"做了"

**根因分析：**
- LLM 不知道工具实际执行结果（本质是概率模型，天然倾向"讨好"用户）
- 系统提示中缺乏"必须诚实报告失败"的强制约束
- 工具结果注入到对话历史后，LLM 可能"选择性遗忘"失败信息
- 没有机制在最终回复前做"结果一致性校验"

## 用户故事

**As a** 岛主用户
**I want** AI 诚实告诉我每个操作的执行结果，失败了就说失败
**So that** 我能信任 AI 的信息，不会因为虚假陈述做出错误决策

## 范围

### In Scope

- **系统提示强化** — 在 SYSTEM_PROMPT 中新增"诚实原则"模块，用强约束语言要求 AI：
  - 必须根据工具返回的实际结果回复，不得编造
  - 工具失败时必须明确告知用户"XX 操作未成功：原因"
  - 没有执行工具调用时，不得声称已完成
  - 不确定是否成功 → 说"不确定"，查执行记录后再说
- **最终响应前注入校验提示** — 工具循环结束后、最终流式输出前，注入一条系统消息：
  ```
  你刚刚执行了以下工具调用：[summary]。请在回复中如实描述每个工具的执行结果。
  如果某个工具失败了，必须说明失败原因，不要编造成功。
  ```
- **工具结果摘要** — 收集所有工具调用的成功/失败状态，构建摘要文本注入最终响应上下文
- **幻觉检测日志** — 当检测到工具失败但 LLM 声称成功时，记录到 tool_log_db 标记为 "suspected_hallucination"
- **权限拒绝后的强制回退** — 工具被权限拒绝后，注入强约束信息到对话历史："该操作已被安全规则拒绝，禁止在回复中声称已完成"

### Out of Scope

- 基于外部事实库的自动事实核查（初期不做，成本太高）
- 多模型交叉验证（后期考虑）
- 用户举报反馈闭环

## 验收标准

1. **AC1**: 工具调用失败返回 error 后，AI 回复中明确包含失败原因，不编造"已完成"
2. **AC2**: 权限拒绝场景下，AI 回复不出现"我帮你做了"、"已完成"等虚假陈述
3. **AC3**: 无工具调用的纯对话中，AI 不声称自己"执行了"任何具体操作
4. **AC4**: 用户追问"你到底做了没有"时，AI 如实回答实际执行情况
5. **AC5**: 连续 2 次工具调用失败后，AI 主动告知用户当前困难而非继续尝试
6. **AC6**: 最终响应前的校验提示生效：LLM 回复中工具结果与实际执行记录一致

## 技术要点

- **`agent.py`** — `agent_chat_stream()` 函数的 `_run_tool_loop` 中：
  1. 收集所有工具执行结果到 `_tool_results_summary` 列表
  2. 工具循环结束后、调用 `_stream_final_response()` 前，注入校验提示
  3. 权限拒绝时注入强约束的 user 消息
- **SYSTEM_PROMPT** — 在 `agent.py` 中新增"诚实与透明"段落，最高优先级
- **`tool_log_db.py`** — 新增 `log_suspected_hallucination()` 函数

**建议系统提示原文（新增）：**
```
## 诚实与透明（最高优先级，不可违反）

你是用户的伙伴，不是仆人。诚实是伙伴关系的基石。
1. 工具调用成功 → 如实告知结果
2. 工具调用失败 → 明确说"XX 失败了：原因"，不编造、不美化、不模糊
3. 没有执行操作 → 绝不说"我已经做了"，可以说"我还没做"或"需要我做吗"
4. 权限被拒绝 → 告知用户"该操作被安全规则拒绝"，不换个说法暗示已执行
5. 不确定是否成功 → 说"我不确定是否成功，建议你检查一下"
违反以上任何一条都是在背叛用户的信任。比做错更糟糕的是说谎。
```

## 业务价值

- 用户信任是管家产品的基石，一次欺骗可能导致用户放弃使用
- 诚实报告失败让用户能做正确决策（如手动操作、换方案）
- 与其他 AI 产品形成差异化：岛主是诚实的伙伴
